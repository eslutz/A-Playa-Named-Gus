---
name: movie-night
description: Find a Jellyfin movie or episode for the current profile, play it on a selected player, or review a missing title in Discover.
---
Use Filter Library Items for constraints such as year, runtime or genre. Use Find Library Items for a title. Show choices when multiple editions or episodes fit. Carry the selected Library Item into playback.

For a named room, find controllable Jellyfin players and ask which device the person means when names overlap. Use the selected player's playback action and report its returned status. A request that was sent may still need verification on the target.

When the person asks to request a missing movie or show, find it with Find Discover Titles. Use the returned Discover Title, review the quality and TV seasons with the person, and use Request Discover Title. The request action obtains its own confirmation. A Discover Title belongs to Seerr and cannot be used as a Jellyfin playback item.
