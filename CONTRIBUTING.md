# Contributing to A Playa Named Gus

Thanks for helping improve A Playa Named Gus.

Contributor guidance lives in the
[Contributing wiki page](https://github.com/eslutz/A-Playa-Named-Gus/wiki/Contributing).

Changes must go through a pull request targeting protected `main`. GitHub CI runs
on PRs and all required checks must pass before a squash merge. Do not push directly
to `main` or bypass its protection. Xcode Cloud tests merged `main` and distributes
successful internal-only archives through TestFlight. [Gate details](Documentation/AppStore/pipeline-policy.md).
