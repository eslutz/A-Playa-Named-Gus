# Seerr integration implementation plan

**Goal:** Implement the Seerr Discovery experience and deliver a validated internal TestFlight release.

**Authority:** The user's October 25 instruction accepts Discovery for implementation and authorizes filling remaining visual gaps with existing Gus patterns. Use the current Gus iPhone Sketch Discovery frames and `Documentation/Seerr-design.md` behavioral contracts. Other redesign areas remain outside this feature.

**Architecture:** Native Foundation transport with isolated per-connection cookies; Codable values; an account-scoped Observation connection store; feature-owned, revision-guarded catalog/request state. Reuse existing adaptive root navigation, artwork, Jellyfin playback and content restrictions. No new runtime dependencies. OS 26 minimum; Xcode 27.1; warnings block release.

## Work

- [ ] Transport and contracts: validate stable Seerr 3.x, local/Jellyfin login, private cookie persistence, catalog/details/person/seasons and request APIs. Pin permission/status/quota semantics to official source and exercise fixtures.
- [ ] Connection and navigation: Discover entry, settings entry, native URL → sign-in setup, reconnect/expiry/offline states, account/device scoping, explicit disconnect and independent hide/restore.
- [ ] Catalog: featured title, independent artwork shelves, dedicated paged grids/list/search, richer movie/series/person/season detail and accessible Jellyfin identity matching.
- [ ] Requests: fresh account/media/quota eligibility, exact eligible season payload, explicit review/submit, authoritative confirmation, unknown-result reconciliation, personal history/cancellation and permitted manager decisions.
- [ ] Supported secondary capabilities: endpoint/permission-gated filters and options; represent server administration through explicit Seerr links where native support is absent. Never render a nonfunctional control or claim unsupported behavior.
- [ ] Documentation and validation: update source-status records and companion documentation, regenerate project, localize user-facing strings, format, test warning-free on all supported destinations, exercise deterministic Seerr fixture UI and account/restriction transitions.
- [ ] Release: isolate intended changes on current protected-main base while preserving the dirty design checkout, submit PR, pass required CI, merge, run exact-main full TestFlight workflow, inspect warnings/logs, verify processing and internal group access.

## Review focus

1. Session replacement/disconnect or permissions changing while a request is awaiting a response must not expose stale data or enable stale mutations.
2. A timed-out mutation must retain its payload and require authoritative readback before retry.
3. Missing/unknown statuses, unavailable artwork, a failed feed/page and empty results must remain truthful and recoverable.
4. Specials (season 0), partial series availability and Standard/4K status are distinct; requests must never include unavailable choices.
5. Seerr availability does not prove playback access. Match external identity through the signed-in Jellyfin account and apply current restrictions before opening a title.
