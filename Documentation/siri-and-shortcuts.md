# Siri and Shortcuts

Gus exposes actions for the signed-in Jellyfin profile. The main app, SiriKit audio handler, Watch app, and system extensions have different execution environments. Use the existing provider, session lease, content restrictions and playback services for operations from each environment.

## Actions and system surfaces

| Surface | Implementation | Qualification |
| --- | --- | --- |
| Siri and Shortcuts on OS 26+ | The original Play Media title parameter remains compatible. The shortcut provider registers common phrases. Library entities are reusable inputs and results. Find in Library returns a list, and the separate Show Library Search Results action opens the in-app search. | Test cold restore, ambiguity, locked invocation, offline playback, cancellation, restricted titles and profiles sharing a server. |
| OS 27 structured media | Song, album and audiobook schemas have AudioSearch queries and a play action on iOS/iPadOS, macOS and visionOS. iPhone can prepare a background queue or insert into its existing queue with Play Next or Play Last. Mac and Vision Pro hand playback to the foreground scene. The system search schema uses the SDK-supported platforms. Apple TV uses the older search and video protocols. | Inspect the compiled metadata and try actual Siri on each supported device. An ordinary shortcut can work on a device with Apple Intelligence turned off. |
| System discovery | Spotlight associates permitted browsed media with typed entities. When enabled, the app associates visible items with user activities and suggests recent items. The transferable representation revalidates the account and exports a shareable Gus URL. | Revoke consent, change the rating policy, sign out and switch to another profile on the same server. Check cold Spotlight and shared-link launches. |
| Widgets and downloads | The app and its extensions exchange a minimal local snapshot. Settings controls personal history and Lock Screen title visibility. Supported controls open Search or Downloads. The iOS download Live Activity reports batch progress. | Check each family on a real Home Screen, Lock Screen, Today View, Control Center and Watch. Apple controls refresh timing and redaction. |
| Apple Watch | A separate provider exposes downloaded audio using the Watch’s own files and account. Watch navigation handles Resume, Browse and Downloads. | Test independently of the phone, with a paired audio route, missing files and an account switch. |
| Remote playback | Resolve a saved player against fresh controllable Jellyfin sessions. Commands require confirmation and report the outcome. The opt-in iOS 27 remote Now Playing extension displays status. | Test two Jellyfin clients, identical names, reconnects, unsupported commands and lost acknowledgments. Shared transport, SharePlay and AirPlay are different routes. |

Apple documents the public integration contracts for [App Shortcuts](https://developer.apple.com/design/human-interface-guidelines/app-shortcuts), [audio playback](https://developer.apple.com/documentation/mediaintents/responding-to-audio-search-and-playback-requests), [Spotlight entities](https://developer.apple.com/documentation/appintents/making-app-entities-available-in-spotlight) and [remote Now Playing](https://developer.apple.com/documentation/nowplaying/publishing-remote-media-sessions).

## Privacy and automation

- A saved entity identifies a provider, server, user, resource type and item. A fresh lookup checks the active account, content policy and operation permissions. A queued app handoff carries its originating credential installation. Publicly shared item links intentionally carry only server, provider and item identifiers.
- Explicit searches work with personal suggestions turned off. Recent activity is opt-in per profile. **Show Titles on the Lock Screen** is a separate preference and defaults off. On iPhone or Watch, a widget family can also be visible while locked, so its shared snapshot omits the title when the preference is off. A person’s own shortcuts and Apple’s Now Playing UI have their own behavior.
- Set personal favorite and completion state to the chosen value. Household actions use an explicit confirmation. Seerr requests keep their own title identity, account revision, eligible seasons, quota and quality checks. Read the returned status before repeating a request. A recording timer, guide program and a playable Jellyfin library item are different objects. A verified owner-only playlist can be edited without a household confirmation. Deferred edits recheck its access list.
- App Intents work with the user's own Jellyfin and configured Seerr servers. The app adds no collector, synchronization service or AI provider for Siri. The optional natural-language search uses Gus’s existing intelligence settings.

## Internal Siri AI developer preview

With Xcode 27.3 beta or a compatible newer SDK, use the explicit `-xcconfig Config/SiriDeveloperPreview.xcconfig` override for a dedicated local preview build. The ordinary project retains OS 26 compatibility. The preview configuration raises the supported deployment target used in that build, enables `GUS_SIRI_AI_PREVIEW` and includes `Skills.skillsbundle`. Keep evaluation outputs outside the repository.

The candidate annotates the ordinary shortcut operations as tools, provides a validated transient movie filter, an entity card, and skills for movie night and offline listening. Use a fictional profile and the physical-device Siri evaluation in the UI test target. Evaluate requests with and without an app mention, title ambiguity, incorrect accounts, and the actual review dialog for household writes. In the preview, adding even one tool changes Siri's dispatch for the entire app. Verify parity across built-in phrases before promoting any new configuration. Apple currently limits these custom preview experiences to development signing and Internal TestFlight. [Siri AI developer preview](https://developer.apple.com/documentation/appintents/siri-ai-developer-preview) · [Tool dispatch and availability](https://developer.apple.com/documentation/appintents/bringing-custom-actions-and-content-to-siri) · [Device evaluations](https://developer.apple.com/documentation/sirievaluations/evaluating-your-apps-integration-with-siri)

The same preview configuration enables `GUS_SIRI_VIDEO_27_3` on iOS, iPadOS, tvOS and visionOS. Gus pairs `.video.playContent` with a `MediaIntents.VideoSearch` query for movies, shows, seasons, episodes and eligible freeform content. A title search uses the active library. URL searches accept scoped Gus links. An unspecified request uses Continue Watching only when personal history suggestions are enabled. A show or season request prefers an admitted next episode and otherwise starts with an eligible episode in that selection. Freeform results currently cover trailers and live channels with enough metadata to classify explicit content. Other library videos remain available through Play Library Video. [Video use-case group](https://developer.apple.com/documentation/appintents/app-schema-domain-video) · [Video search criteria](https://developer.apple.com/documentation/mediaintents/videosearch/criteria-swift.enum) · [Play content](https://developer.apple.com/documentation/appintents/appschema/videointent/playcontent)

The installed Xcode 27.2 SDK does not publish the 27.3 video declarations. The preview source has been syntax-checked. Compilation with the actual SDK, App Intents metadata export, and a spoken end-to-end request on each eligible platform remain acceptance steps. With Xcode 27.3 or later, verify that metadata pairs each supported video entity's value query with `playContent`, then exercise a same-title collision, a season request, an out-of-scope link and a restricted title on a fictional profile. [Xcode 27.3 release notes](https://developer.apple.com/documentation/xcode-release-notes/xcode-27_3-release-notes)

## Provider and hardware gates

- **HomePod.** Try the iPhone/iPad AirPlay path in a real home first. Direct HomePod service playback requires Apple program eligibility, an OAuth service and endpoints reachable by the speaker. A private Jellyfin URL and a user token do not supply that provider infrastructure. [SiriKit Cloud Media](https://developer.apple.com/documentation/sirikitcloudmedia)
- **Apple TV.** Test Gus's in-app search, video playback and eligible Siri Remote interactions on the target hardware. Apple's catalog-wide Universal Search distribution is a separate program for premium subscription video providers. No partner feed is configured here. The newer video schema requires the paired 27.3 video query and a compatible SDK. [Video Partner Program](https://developer.apple.com/programs/video-partner) · [Video schemas](https://developer.apple.com/documentation/appintents/app-schema-domain-video)
- **CarPlay and SharePlay.** Verify SiriKit audio on a signed iPhone and a real vehicle, including locked and disconnected conditions. Separately verify the native group invitation with two participants. Parked video requires separate approval and vehicle support. [CarPlay qualification](https://github.com/eslutz/A-Playa-Named-Gus/issues/70) · [Parked video](https://github.com/eslutz/A-Playa-Named-Gus/issues/14) · [SharePlay](https://github.com/eslutz/A-Playa-Named-Gus/issues/8)
