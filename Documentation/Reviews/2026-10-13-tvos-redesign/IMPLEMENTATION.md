Implementation/local verification only. No push, PR, merge, deployment, release, entitlement/account or signing-file changes are authorized or performed.

The preceding Swiftfin research remains in the original checkout at `Documentation/Research/2026-10-13-swiftfin-tvos/REPORT.md`, with official pinned source/release references and inspected historical/demo images. This implementation does not copy Swiftfin code, assets, dependencies, routing or player controls. The earlier report’s duplicate-entry playlist proposal is superseded by merged PR #21: Jellyfin owns playlist/collection names, membership, ordering and permissions; native lists deduplicate item IDs, and legacy Gus lists require explicit import. ## Implemented

- Native TV sidebar retaining customizable Gus destinations, dedicated Search and launch/deep-link search routing; browsing tabs no longer automatically host the TV search keyboard.
- Focus-driven cinematic unified Next Up, retaining the exact builder output, order and recovery destinations; first recently-added section is the empty-Next-Up cinematic fallback. Artwork is decorative, debounced and respects Reduce Motion through the existing native image loader.
- Full TV page width, adaptive 220–280-point library cards, safe focus breathing room, two-line TV titles and watched/resume indicators with accessible values. Shared mobile/pointer title limits remain unchanged.
- Independent TV detail artwork/title/action hierarchy, Resume/Play, native More actions, full scrollable synopsis, episodes/seasons and existing related content. Series primary actions resolve to a normal Next Up episode or an unfinished loaded-season episode; independent playlist cursor entries are excluded. Empty series and season/collection/book containers are not direct video targets. Rating admission is rechecked before presenting the selected episode.
- Native `@FocusState` links with session-owned per-screen/per-rail identity bookmarks and horizontal scroll targets. Show All records its invoking control; a newly loaded rail does not override existing screen focus history. Pushed detail focus cannot overwrite the parent Home rail’s restoration context. Removed IDs resolve to a clamped neighbor. The runtime follow-up repairs the retained-parent boundary and verifies native Back restoration to that neighbor. Data updates do not repeatedly issue focus requests while a sidebar/menu is in use; in-place focus fallback remains owned by the native engine.
- Optional fast Account menu over existing saved-session switching, grouped by server with active checkmark. A valid saved account switches directly, with no second confirmation or new PIN/security policy. Missing credentials use the existing sign-in sheet with explicit Cancel; Manage Accounts goes to Settings. Existing root session identity replacement cancels old video/tasks, stops audio, deactivates list transport, clears account-specific navigation/focus/cache/Top Shelf boundaries and retains scoped saved data. Repeated/cancelled remote behavior requires runtime acceptance.
- AVKit display criteria matching, native Playback Info and Next Episode actions, safe controller dismantling, background TV pause and preservation of pause/rate on server track rebuild. Foregrounding does not automatically resume video. On tvOS, AVKit owns system video Now Playing because its publishing toggle is unavailable; other platforms retain Gus’s existing controller. Playback Info distinguishes negotiated delivery from source video metadata and does not promise HDR/Dolby Vision/Atmos output.
- New English source entries in the String Catalog, regenerated XcodeGen snapshot, roadmap and isolated companion wiki/support edits.

Platform composition lives in `Sources/Platform/TV/`; shared domain/provider/session stores remain intact. Native buttons, menus, search, focus and AVKit supply interaction. No custom router, decoder, theme engine, PIN policy, autoplay trailer carousel, trickplay scrubber or third-party runtime dependency was introduced.

The retained-parent removed-item regression now passes: navigation-state snapshots protect the parent bookmark until its native focus link can restore the neighbor; unaccepted focus experiments were removed. Manual acceptance remains open for 1080p/4K couch readability, native focus scaling/clipping, exact focus after Back/Menu, grid paging and sidebar entry/exit, native menus/keyboard, repeated or cancelled account/re-auth/Play flows, VoiceOver speech/order/announcements, Reduce Motion/contrast, physical display matching/HDR/audio and signed iCloud/device sync. This feature does not claim release readiness or signed acceptance.

## Required compatible-TV acceptance

1. Launch with Next Up populated and empty; verify first focus, fallback artwork, exact activity order, missing-reference recovery and Show All.
2. Focus an offscreen Next Up/latest card, open detail, focus More/Synopsis or an episode, then Back repeatedly. Return to the original parent rail/card and scroll position. Repeat after reorder/removal and after a data refresh while the sidebar is focused; no background focus stealing.
3. Browse several library pages, change/reset filters, open long-title/missing-art items and return. Confirm poster size, focus-safe edges and stable paging/error recovery at 1080p/4K.
4. Use only the remote for Search, full synopsis and native menus. Menu/Back dismisses the current keyboard/menu/modal/stack level, without double-pop or unexpected account change.
5. Switch between two users and same-name users on different servers; repeat quickly, select the active user, cancel missing-token re-auth and interrupt preparation. Verify old video/audio, artwork, search, Top Shelf, progress writers and list transport do not leak or revive. No routine switch confirmation should appear.
6. Play direct/remux/transcoded video, choose audio/subtitles repeatedly while paused/playing, seek chapters, use Next Episode, background during loading and close during preparation/rebuild. Verify pause/rate/position, cancellation, progress/stop reports and native remote transport. Explicit Jellyfin playlists retain their own ordering/cursor and collections remain groups.
7. Exercise real VoiceOver and accessibility settings; inspect source metadata versus actual receiver/display output. Complete existing signed private-sync gates separately.
